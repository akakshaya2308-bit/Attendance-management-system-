# 📊 Attendance Management System

A simple, customizable, and privacy-friendly **Attendance Management System** built using **HTML, CSS, and JavaScript**.

The system allows anyone to create their own student list, manage attendance, customize class details, and export attendance records without needing a backend or database.

---

## ✨ Features

- 👨‍🎓 Add students with custom names and register numbers
- ✏️ Edit student details
- 🗑️ Delete students
- 📅 Select attendance date
- ✅ Mark students Present
- ❌ Mark students Absent
- 🔄 Reset attendance for a selected day
- 📌 Mark all students Present or Absent
- ⏱️ Customize the number of hours per day
- 🏫 Customize institution/class name
- 📝 Customize system title
- 📈 Automatically calculate attendance percentage
- 📊 View total students and attendance statistics
- 📥 Export attendance as CSV
- 💾 Automatically save data using browser `localStorage`
- 🔐 No built-in student names or register numbers
- 📱 Responsive design for desktop and mobile
- 🌐 Works directly in a web browser
- 🚫 No backend or database required

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling and responsive UI
- **JavaScript** – Application logic
- **LocalStorage API** – Local data persistence
- **CSV** – Attendance export format
